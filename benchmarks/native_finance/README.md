# Native finance execution acceptance

Two deterministic tasks validate the directory execution pipeline: a positive
and a negative revenue growth calculation, generated JSON/Markdown, binary file
copying, separate grading, immutable artifact collection, rejudging and export.

Run `python examples/run_native_benchmark.py` from the repository root.
This fixture calls no model and is not an official finance benchmark result.
The public input directory is copied to each fresh workspace. Ground truth and
Judge programs are materialized only after Target execution has ended.
