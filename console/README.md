```powershell
cd console
npm run dev
npm test
```

原始提交 c7b8596 为页面与静态服务器，83c082f 为设计参考图。合入审查修复了非法 URL 导致服务器异常、目录前缀越界、token 分解重复计数及不安全的 Key 名称输入。测试验证静态服务边界和模拟 DOM 下的路由/Run 标签渲染，不代替浏览器视觉验收或真实 API 集成测试。
